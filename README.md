# Sistema de Controle de Estoque

## Sobre o projeto
Desenvolvi este projeto em Python para praticar lógica de programação e simular o controle de estoque de uma empresa.

Minha ideia foi criar um sistema que permitisse registrar entradas e saídas de produtos, consultar quantidades disponíveis e identificar situações de estoque baixo.

## Funcionalidades
- Consultar a quantidade disponível de um produto.
- Registrar entrada de mercadorias.
- Registrar saída de mercadorias.
- Impedir retiradas superiores ao estoque disponível.
- Verificar o estoque mínimo.
- Alterar o nome do produto.

## Conhecimentos utilizados
Python, variáveis, operações matemáticas, estruturas condicionais (`if`, `elif`, `else`) e laços de repetição (`while`).

## Como executar
Execute o arquivo Python do projeto em um ambiente com Python 3 instalado.

**Observação:** Sistema acadêmico que controla um produto por vez, com dados armazenados temporariamente.
